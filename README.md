# 📝 Quiz Web App

An interactive and responsive quiz web application where users can test their knowledge by answering multiple-choice questions. The app shows instant feedback on each answer and displays the final score at the end, which makes learning fun and engaging.

## Features
- Multiple-choice questions with a clean, simple interface
- Instant feedback for correct and wrong answers
- Score tracking throughout the quiz
- Final result screen with total score
- Timer for each question or for the whole quiz
- Option to restart and play again
- Fully responsive design for mobile, tablet, and desktop

## How It Works
1. The user starts the quiz from the home screen.
2. Questions appear one by one with multiple options.
3. The user selects an answer and gets instant feedback.
4. The score updates after each question.
5. At the end, the final score and result are displayed.

## Purpose
Built to practice front-end web development concepts such as DOM manipulation, event handling, dynamic content rendering, and responsive UI design.
